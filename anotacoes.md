# Anotações
## Alguns comandos do git
- **add**
- **commit**
- **push**

1. *add*: escolhe quais mudanças vão entrar no próximo commit (coloca no "staging").
   Assim posso salvar só parte do que alterei, e não tudo de uma vez.
2. *commit*: tira uma "foto" do projeto naquele momento, como um save de game.
   A foto fica guardada **no meu computador**, junto com uma mensagem, o autor e a data.
3. *push*: envia os **commits** (as fotos) que ainda não estão no GitHub
   para o repositório remoto, chamado de `origin`.
4. *git log --oneline*: mostra o histórico de commits, um por linha.
   Serve para conferir se o `HEAD` (meu computador) e o `origin/main` (GitHub) estão juntos.
